# Mã CIS Mức Độ Mô Tả Rủi Ro Khuyến Nghị Khắc Phục (Remediation)
CẤU HÌNH GẶP LỖI (VULNERABLE)

Trước khi tối ưu

  • Kích thước Image lớn (~800MB) do chứa compiler & build cache.
  • Chạy trực tiếp dưới quyền Root (UID 0).
  • Sẵn sàng công cụ curl, bash, netcat cho kẻ tấn công leo thang.
  • Lộ thông tin nhạy cảm qua ENV.
$ docker run -d --privileged \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -e API_KEY=AKIAIOSFODNN7EX \
  vulnerable-app:latest
ĐỀ XUẤT VÁ LỖI TỰ ĐỘNG (REMEDIATION - SLIDE 10 & 11)

Sau khi áp dụng Multi-stage build & Hardening

  • Kích thước giảm còn 30MB, loại bỏ toàn bộ shell thừa.
  • Cắt giảm toàn bộ quyền với --cap-drop=ALL.
  • Lọc cuộc gọi hệ thống bảo vệ Kernel qua Seccomp profile.
  • Giới hạn RAM 512MB & 1.0 CPU chống sập hệ thống (DoS).
$ docker run -d \
  --user 1001:1001 \
  --cap-drop=ALL --cap-add=NET_BIND_SERVICE \
  --security-opt seccomp=profile.json \
  --memory="512m" --cpus="1.0" \
  --read-only \
  hardened-app:v1.0
